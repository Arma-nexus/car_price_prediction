# Car Price Prediction using Machine Learning

## Project Overview
Car Price Prediction is a machine learning web application developed using Python and Streamlit. It predicts the estimated price of a car based on its year, mileage, brand, and fuel type.

## Technologies Used
- Python
- Pandas
- NumPy
- Streamlit
- Scikit-learn
- Linear Regression

## Features
- Dataset preview
- Car price prediction
- Model training using Linear Regression
- Model performance evaluation
- User-friendly web interface

## Machine Learning Algorithm
Linear Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## How to Run

1. Install the required packages:

```bash
pip install -r requirements.txt
```

2. Run the application:

```bash
streamlit run car.py
```

## Dataset
The application uses a CSV dataset containing car details such as year, mileage, brand, fuel type, and price.
